📌 md-memo

One-click web article clipper to Markdown

Features

  • Tiny loader bookmarklet — updates automatically, nothing to reinstall
  • Core logic served from peek.js on GitHub Pages
  • Extracts article content with readability AI
  • Converts to clean Markdown with YAML metadata
  • Copies instantly to clipboard
  • Works on most websites

Setup

Customize your bookmarklet settings, then click "Generate Bookmarklet" to get your personalized version.

📍 How to Install

Desktop (Chrome, Firefox, Safari, Edge):
  1. Right-click the button below and select "Bookmark Link"
  2. Choose your Bookmarks Bar as the location
  3. Name it "md-memo" or similar

Mobile (Safari on iOS):
  1. Copy the code below
  2. Create a new bookmark and paste into the URL field
  3. Name it "md-memo"

📖 How to Use

  1. Navigate to any article you want to save

  3. Wait for "Extracting..." notification
  4. See "✓ Copied to clipboard!" when done
  5. Paste into your Obsidian/Notion/Logseq vault
